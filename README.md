A one-line apology from an office printer to the people who keep jamming it — written for make.fun's "The Printer Apology" bounty ($2 in USDC). The program writes a single 90-character apology to `/output/entry.txt`; an AI judge picks the funnier line in head-to-head pairs.

The line: *"I'm sorry I ate your boarding pass. It was the only document in this office with a future."*

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
